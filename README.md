# دفتر مهلة

موقع مستقل يدير مشروع «مهلة»: رؤوس أموال الشركاء، وعملاء كل شريك، والسداد.

## الأدوار
| الدور | يشوف |
|---|---|
| صاحب الدفتر (`admin`) | كل الشركاء وكل العملاء، ويعدّل كل شيء: رأس المال، والعملاء، وصور السندات، ونسبة الربح، ودخول الشركاء |
| الشريك | صفحته فقط: رأس ماله وعملاؤه والسداد، اطّلاع بلا تعديل |

## النشر (مجاني)
1. قاعدة بيانات Postgres مجانية من **neon.tech**، وتنسخ منها رابط الاتصال (Connection string).
2. في **render.com**: New ← Blueprint ← تختار هذا المستودع (يقرأ ملف `render.yaml`).
3. تحط القيم:
   - `DATABASE_URL`: رابط Neon
   - `ADMIN_PASSWORD`: كلمة مرور صاحب الدفتر (اسم المستخدم `admin`)
4. بعد ما يشتغل: تدخل بحساب `admin`، ومن «الملخص» تستورد بيانات الدفتر القديم مرة واحدة.

ملاحظة: الخطة المجانية في Render تنوّم الموقع بعد 15 دقيقة بدون زيارات، وأول فتح بعدها ياخذ تقريبًا دقيقة.

## التشغيل محليًا
```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt
ADMIN_PASSWORD=xxxx .venv/bin/python -c "from app import app; app.run(port=5000)"
```

## الملفات
- `app.py`: الجداول والصفحات والصلاحيات
- `templates/`: صفحة الدخول وصفحة الدفتر
- `static/app.js`: واجهة الدفتر والحاسبة
- `index.html`: صفحة GitHub Pages تحوّل إلى الموقع على Render
